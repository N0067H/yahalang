<p align="center"><a href="README_EN.md">English</a> / 한국어 / <a href="README_JP.md">日本語</a></p>

Yahalang은 *치이카와* 우사기의 랩 후렴에서 문법을 따온 난해한 프로그래밍 언어입니다.\
말소리로 된 구절을 명령으로 쓰고, 스택에 값을 쌓아 계산합니다. 부호 있는 64비트 정수와 정수 배열을 다루며 한국어·영어·일본어 표기를 지원합니다.

## 시작하기

Rust와 Cargo가 설치된 환경에서 빌드하고 실행합니다.

```sh
cargo build
cargo run -- run examples/hello_world.yaha --lang ko
```

`Hello, world!`와 줄바꿈을 출력합니다. 저장소의 예제는 모두 한국어로 작성되어 있으므로 `--lang ko`를 붙입니다.

직접 입력하며 실행하려면 REPL을 켭니다.

```sh
cargo run -- repl --lang ko
```

```text
yaha> 하야하 뿌루뿌루 야하
yaha> 뿌루
yaha> 야하
yaha> :stack
[4]
yaha> 이이이야하 뿌루루
4
yaha> :q
```

2를 넣고 복제한 뒤 더하는 예제입니다. REPL은 입력 사이에 값을 유지합니다. [REPL 사용법](#repl)에서 여러 줄 입력과 초기화 방법을 설명합니다.

## 스택과 숫자

명령은 스택 맨 위의 값을 사용합니다. 이 문서에서 스택은 왼쪽이 아래, 오른쪽이 위입니다. `[7, 2]`라면 2가 맨 위에 있습니다.

숫자는 `하야하`로 시작하고 `야하`로 닫습니다. 사이에 있는 `뿌루`의 개수가 값입니다.

| 코드 | 값 |
| --- | --- |
| `하야하 야하` | 0 |
| `하야하 뿌루 야하` | 1 |
| `하야하 뿌루뿌루 야하` | 2 |

음수는 숫자를 만든 뒤 `우라 얏`으로 부호를 바꿉니다. 소수는 지원하지 않습니다.

```text
하야하 뿌루뿌루 야하
하야하 뿌루뿌루뿌루 야하
야하
이이이야하 뿌루루
```

2와 3을 쌓고 더한 뒤 `5`를 출력합니다. 출력한 값은 스택에서 사라집니다.

아래 표의 `a`, `b`는 값, `A`는 배열 참조입니다. 표에는 명령이 성공했을 때 바뀌는 부분만 적었습니다. 그 아래에 있던 값은 그대로 남습니다.

| 구절 | 스택 변화 | 동작 |
| --- | --- | --- |
| `뿌루` | `a → a, a` | 맨 위 값 복제 |
| `우라 뿌루` | `a → 없음` | 맨 위 값 버리기 |
| `이야 뿌루` | `a, b → b, a` | 맨 위 두 값 교환 |

배열에 `뿌루`를 쓰면 같은 배열을 가리키는 참조가 하나 더 생깁니다. 내용을 따로 복사하려면 [배열 복사](#참조-복제와-내용-복사)를 사용합니다.

## 구절 읽는 규칙

소리는 정해진 표기 그대로 씁니다. `이야`, `우라`는 가능하지만 대시를 넣은 `이-야`, `우-라`는 오류입니다. 주석과 문자·문자열 리터럴 문법은 없습니다.

공백과 줄바꿈은 구절을 끊지 않습니다. `이이이야하` 다음 줄에 `뿌루루`를 써도 정수 출력 한 명령입니다. 들여쓰기는 자유롭습니다.

소리를 붙여 써도 되며, 겹치는 소리는 긴 쪽부터 읽습니다. `뿌루뿌루`는 복제 두 번이지만 `뿌루루`는 별개의 소리입니다.

명령이 합쳐지는 것을 막으려면 `;`로 경계를 표시합니다.

| 코드 | 해석 |
| --- | --- |
| `이이이야하 뿌루루` | 정수 출력 |
| `이이이야하 ; 뿌루` | 정수 입력 후 복제 |
| `우라 야하야하` | 조건 블록 닫기 |
| `우라 야하 ; 야하` | 뺄셈 후 덧셈 |
| `야하야하` | 덧셈 두 번 |

하나의 구절이나 숫자 안에 `;`를 넣을 수는 없습니다. 예를 들어 `하아 ; 핫`, `야다 ; 뿌루`, `하야하 ; 야하`는 오류입니다.

## 계산과 비교

두 값을 쓰는 연산은 아래 값을 왼쪽, 맨 위 값을 오른쪽 피연산자로 삼습니다. `[7, 2]`에서 뺄셈하면 `[5]`가 됩니다.

| 구절 | 스택 변화 |
| --- | --- |
| `야하` | `a, b → a + b` |
| `우라 야하` | `a, b → a - b` |
| `핫` | `a, b → a × b` |
| `우라 핫` | `a, b → a ÷ b`의 정수 몫 |
| `우라 핫핫` | `a, b → a % b` |
| `우라 얏` | `a → -a` |
| `하아 이야` | `a, b → a < b`이면 1, 아니면 0 |
| `하아 핫` | `a, b → a == b`이면 1, 아니면 0 |
| `하아 야하` | `a, b → a > b`이면 1, 아니면 0 |

나눗셈은 0 방향으로 소수 부분을 버립니다. -7을 2로 나누면 -3이고, 나머지는 -1입니다. 0으로 나누거나 계산 결과가 64비트 정수 범위를 벗어나면 오류입니다.

비교는 정수끼리만 가능합니다. 두 입력값을 소비하고 결과 하나를 남기므로, 원래 값이 필요하면 먼저 복제해야 합니다. 같지 않음은 같음의 결과를 0과 비교하고, 이하·이상은 각각 큼·작음의 결과를 0과 비교해 표현할 수 있습니다.

## 조건과 반복

| 시작 | 끝 | 조건값 처리 |
| --- | --- | --- |
| `이야 야하야하` | `우라 야하야하` | 맨 위 정수를 꺼내 0이 아니면 본문 실행 |
| `이야 야다야다` | `우라 야다야다` | 맨 위 정수를 남겨 두고 0이 아닌 동안 반복 |

조건값은 정수여야 합니다. 블록은 최대 128단계까지 중첩할 수 있으며, 여는 구절과 닫는 구절의 종류가 맞아야 합니다.

### 조건문

```text
이이이야하
이이이야하
하아 이야
이야 야하야하
    하야하 뿌루 야하
    이이이야하 뿌루루
우라 야하야하
```

첫 번째 입력이 두 번째보다 작으면 `1`을 출력합니다. 그렇지 않으면 아무것도 출력하지 않습니다. `하아 이야`가 남긴 비교 결과는 조건 블록이 꺼내 사용합니다.

### 반복문

```text
하야하 뿌루뿌루뿌루 야하
이야 야다야다
    뿌루
    이이이야하 뿌루루
    하야하 뿌루 야하
    우라 야하
우라 야다야다
```

`321`을 출력하고 스택에 0을 남깁니다. 반복문은 본문을 실행하기 전과 다음 반복으로 돌아갈 때 맨 위 정수를 검사합니다. 본문 끝에는 다음 검사에 쓸 정수가 있어야 합니다. 처음부터 0이면 본문을 건너뛰고, 그 0도 스택에 남습니다.

### 반복 탈출과 실행 종료

`우라 이야`는 가장 가까운 반복문 하나를 빠져나갑니다. 조건문 안에서도 사용할 수 있으며, 중첩 반복에서는 안쪽 반복만 끝냅니다. 스택은 바꾸지 않습니다.

```text
하야하 뿌루뿌루뿌루 야하
이야 야다야다
    우라 이야
우라 야다야다
이이이야하 뿌루루
```

조건값이 3이어도 반복을 끝내고, 뒤의 출력 명령을 실행해 `3`을 출력합니다. 탈출할 때는 다음 반복 검사에 쓸 정수를 남길 필요가 없습니다. 반복문 밖의 `우라 이야`는 구문 오류이며, 탈출 뒤의 코드도 문법 검사를 받습니다.

`얏`은 반복 탈출과 달리 현재 프로그램의 실행을 끝냅니다. 파일 끝에서도 실행이 끝나므로 반드시 넣을 필요는 없습니다. REPL에서는 현재 입력의 실행만 끝내고 다음 입력을 받습니다.

## 입출력

문자는 유니코드 코드 포인트를 정수로 다룹니다. 예를 들어 `가`는 44032입니다. 문자열은 이런 정수를 순서대로 담은 배열입니다.

| 구절 | 입력 또는 출력 | 스택 변화 |
| --- | --- | --- |
| `이이이야하` | 한 줄에서 정수 하나 입력 | 정수 추가 |
| `우라라 이이이야하` | UTF-8 문자 하나 입력 | 코드 포인트 추가 |
| `우라라 야다` | UTF-8 한 줄 입력 | 새 코드 포인트 배열 추가 |
| `이이이야하 뿌루루` | 정수 출력 | 정수 소비 |
| `이이이야하 우라라` | 문자 출력 | 정수 소비 |
| `야다 이이이야하` | 배열을 문자들로 출력 | 배열 참조 하나 소비 |

출력 명령은 자동으로 줄바꿈을 붙이지 않습니다. 줄바꿈도 출력하려면 코드 포인트 10을 문자로 출력하거나, 문자 배열에 포함해야 합니다.

### 정수 입력

```sh
printf '12\n30\n' | cargo run -- run examples/add_two_numbers.yaha --lang ko
```

두 줄을 읽어 합인 `42`를 출력합니다. 정수는 한 줄에 하나씩 입력합니다. 앞뒤 공백은 허용하지만 `12 30`처럼 한 줄에 두 개를 쓰면 오류입니다.

### 문자 입력

```text
우라라 이이이야하
이이이야하 우라라
```

문자 하나를 읽어 그대로 출력합니다. `가`를 입력하면 `가`가 나옵니다. 마지막 명령을 `이이이야하 뿌루루`로 바꾸면 코드 포인트인 `44032`를 출력합니다.

공백과 줄바꿈도 문자로 읽습니다. 다음 문자나 줄바꿈을 미리 소비하지 않습니다. 터미널에서는 Enter를 눌러야 입력이 전달될 수 있으며, 그 줄바꿈은 다음 입력에 남습니다.

### 문자열 입력과 출력

```text
우라라 야다
야다 이이이야하
```

한 줄을 읽어 그대로 출력합니다. `가나다`와 Enter를 입력하면 `[44032, 45208, 45796]`을 만든 뒤 `가나다`를 출력합니다.

문자열 입력은 줄 끝의 LF 또는 CRLF만 제거합니다. 앞뒤 공백, 탭, NUL과 단독 CR은 보존합니다. 빈 줄은 빈 배열이 되고, 개행 없이 끝난 마지막 내용도 읽습니다. 매 입력은 독립된 배열입니다.

길이를 구하려면 출력 대신 `야다 뿌루루`를 씁니다.

```text
우라라 야다
야다 뿌루루
이이이야하 뿌루루
```

`가나다`를 입력하면 `3`이 나옵니다. 길이는 화면에 보이는 글자 수가 아니라 유니코드 코드 포인트 수입니다. 결합 문자나 여러 코드 포인트로 된 이모지는 배열 원소도 여러 개입니다.

문자 배열 출력은 배열을 앞에서부터 읽으며 내용을 바꾸지 않습니다. 빈 배열은 아무것도 출력하지 않습니다. 배열 전체의 문자값을 검증한 뒤 출력하므로, 잘못된 값이 있으면 출력과 스택을 바꾸지 않고 오류를 냅니다. 배열을 계속 쓰려면 출력 전에 `뿌루`로 참조를 복제합니다.

### 입력 종료와 제한

입력 종류에 따라 EOF 처리가 다릅니다.

| 입력 | EOF 처리 | 길이 제한 |
| --- | --- | --- |
| 정수 | 읽을 내용이 없으면 오류 | 줄바꿈을 포함해 한 줄 최대 1,024바이트 |
| 문자 | 문자 시작 전이면 -1, 문자 도중이면 오류 | UTF-8 문자 하나 |
| 문자열 | 마지막 내용이 있으면 배열로 반환, 없으면 오류 | LF·CRLF를 제외하고 한 줄 최대 1 MiB |

문자 입력의 EOF 값인 -1은 유효한 문자값이 아닙니다. 문자로 출력하거나 문자 배열에 넣어 출력하기 전에 EOF인지 검사해야 합니다. [character_echo.yaha](examples/character_echo.yaha)는 이 검사를 포함해 EOF까지 문자를 출력합니다.

잘못된 UTF-8, 유효하지 않은 정수와 길이 제한을 넘는 입력은 오류입니다. 입력 오류가 나도 이미 읽은 바이트는 되돌리지 않습니다. 문자·문자열 입력과 정수 입력은 모두 같은 입력 스트림을 사용합니다.

## 배열

빈 배열은 `야다 하야하`로 만듭니다. 숫자 시작 구절과 달리 뒤에 닫는 `야하`를 붙이지 않습니다. 배열은 정수만 담으며, 인덱스는 0부터 시작합니다.

| 구절 | 스택 변화 | 동작 |
| --- | --- | --- |
| `야다 하야하` | 새 배열 추가 | 빈 배열 생성 |
| `야다 뿌루` | `A, 값 → A` | 끝에 정수 추가 |
| `야다 우라` | `A → A, 값` | 마지막 정수를 제거해 스택에 올리기 |
| `야다 우라라` | `A → A, 복사본` | 독립된 배열로 내용 복사 |
| `야다 뿌루루` | `A → 길이` | 길이 조회 |
| `야다 이야` | `A, 인덱스 → 값` | 원소 조회 |
| `야다 핫` | `A, 인덱스, 값 → 없음` | 원소 수정 |
| `야다 이이이야하` | `A → 없음` | 문자 배열 출력 |

추가·꺼내기는 배열 참조를 남깁니다. 길이 조회·원소 조회·수정·출력은 참조를 소비하므로, 같은 배열을 다시 쓰려면 먼저 `뿌루`로 복제해야 합니다.

### 값 넣고 꺼내기

```text
야다 하야하
하야하 뿌루 야하
야다 뿌루
하야하 뿌루뿌루 야하
야다 뿌루
야다 우라
이이이야하 뿌루루
야다 우라
이이이야하 뿌루루
```

1, 2를 추가한 뒤 역순으로 꺼내 `21`을 출력합니다.

| 실행한 구절 | 스택 |
| --- | --- |
| `야다 하야하` | `[[]]` |
| 1을 넣고 `야다 뿌루` | `[[1]]` |
| 2를 넣고 `야다 뿌루` | `[[1, 2]]` |
| `야다 우라` | `[[1], 2]` |
| `이이이야하 뿌루루` | `[[1]]` |
| `야다 우라` | `[[], 1]` |
| `이이이야하 뿌루루` | `[[]]` |

여기서 대괄호는 스택과 배열 내용을 보여 주기 위한 표기입니다. 위 코드는 기호 없이 작성할 수 있습니다.

### 참조 복제와 내용 복사

`뿌루`는 같은 배열을 가리키는 참조를 복제합니다. 한쪽에서 수정·추가·제거하면 다른 참조에서도 변경된 내용이 보입니다.

`야다 우라라`는 별도의 배열을 만들어 내용을 복사합니다. 원본 참조는 남겨 두고 복사본을 맨 위에 올립니다.

```text
야다 하야하
하야하 뿌루 야하
야다 뿌루
야다 우라라
하야하 뿌루뿌루 야하
야다 뿌루
```

REPL에서 이어서 `:stack`을 입력하면 `[[1], [1, 2]]`가 나옵니다. `야다 우라라` 대신 `뿌루`를 쓰면 `[[1, 2], [1, 2]]`가 됩니다.

### 기존 기호 문법

배열 리터럴과 기호 명령도 계속 지원합니다.

| 기호 | 같은 동작의 구절 |
| --- | --- |
| `[]` | `야다 하야하` |
| `#` | `야다 뿌루루` |
| `@` | `야다 이야` |
| `=` | `야다 핫` |

배열 리터럴의 원소는 쉼표로 구분합니다. `[하야하 야하, 하야하 뿌루 야하]`는 `[0, 1]`을 만듭니다. 배열 안에 배열을 넣을 수는 없습니다.

## REPL

완성된 입력은 바로 실행하고, 스택과 배열은 다음 입력에서도 유지합니다. 숫자·배열·블록·구절이 미완성이면 `...>`에서 이어 받으며, 코드가 완성될 때까지 실행하지 않습니다.

| 명령 | 동작 |
| --- | --- |
| `:stack` | 스택을 아래에서 위 순서로 표시 |
| `:reset` | 스택·배열과 입력 중인 코드 초기화 |
| `:q`, `:quit` | 입력 중인 코드를 버리고 종료 |

구문 오류가 나면 입력 중인 코드만 버립니다. 실행 오류가 나면 오류 시점의 상태를 유지하고 다음 입력을 받습니다. 앞서 실행한 명령을 되돌리지는 않습니다. EOF에 미완성 코드가 남아 있으면 오류를 표시합니다.

완성된 입력끼리는 구절이 합쳐지지 않습니다. 한 줄에 `이이이야하`만 입력하면 정수 입력을 실행합니다. 다음 줄의 `뿌루루`를 기다리지 않습니다.

프로그램의 입력 명령도 REPL 소스와 같은 스트림을 사용합니다. 입력 명령이 실행 중일 때 넣은 줄은 소스가 아니라 프로그램의 입력값으로 읽힙니다.

출력 뒤에 다음 프롬프트가 붙지 않도록 REPL은 필요할 때 화면에 줄바꿈을 추가합니다. 파일 실행에서는 이 줄바꿈을 추가하지 않습니다.

## 언어 설정

`--lang ko`, `--lang en`, `--lang ja`로 소스의 표기를 선택합니다. 한 프로그램 안에서 서로 다른 언어 표기를 섞을 수는 없습니다.

```sh
cargo run -- set lang ko
```

기본 표기를 저장하는 명령입니다. 실행할 때 지정한 `--lang`이 저장된 설정보다 우선하며, 둘 다 없으면 영어를 사용합니다.

구절 구조는 같고 소리 표기만 바뀝니다. 예를 들어 `야다 우라라`는 영어로 `yada urara`, 일본어로 `ヤダ ウララ`입니다.

| 한국어 | 영어 | 일본어 |
| --- | --- | --- |
| 하야하 | hayaha | ハヤハ |
| 하아 | haa | ハア |
| 뿌루 | ppuru | プル |
| 뿌루루 | ppururu | プルル |
| 야하 | yaha | ヤハ |
| 이이이야하 | iiiiyaha | イイイヤハ |
| 우라라 | urara | ウララ |
| 이야 | iya | イヤ |
| 야다 | yada | ヤダ |
| 우라 | ura | ウラ |
| 핫 | hat | ハッ |
| 얏 | yat | ヤッ |

설정 파일은 `lang = "ko"` 형식으로 저장됩니다.

| 운영체제 | 경로 |
| --- | --- |
| Linux | `$XDG_CONFIG_HOME/yahalang/config.toml` 또는 `~/.config/yahalang/config.toml` |
| macOS | `~/Library/Application Support/yahalang/config.toml` |
| Windows | `%APPDATA%/yahalang/config.toml` |

## 오류 확인

기본 오류 메시지는 우사기 말소리로 나옵니다. 원인과 위치를 확인하려면 `--error-style friendly`를 붙입니다.

```sh
cargo run -- run examples/array_access.yaha --lang ko --error-style friendly
cargo run -- repl --lang ko --error-style friendly
```

알 수 없는 소리, 잘못된 구절, 닫지 않은 숫자·블록, 반복문 밖의 탈출 명령은 실행 전에 검사합니다. 실행 중에는 스택 부족, 타입 불일치, 정수 오버플로, 0으로 나누기, 잘못된 배열 인덱스·문자값·입력 등이 오류가 됩니다.

실행 오류가 났다고 스택이 항상 이전 상태로 돌아가는 것은 아닙니다. 명령에 따라 피연산자가 이미 꺼내졌을 수 있습니다. 배열 추가·꺼내기·내용 복사는 스택 부족이나 잘못된 피연산자로 실패할 때 상태를 바꾸지 않습니다. 빈 배열에서 꺼내기도 마찬가지입니다.

문자 배열 출력은 잘못된 문자값을 출력 전에 검사하고, 쓰기·flush에 실패해도 배열 참조를 남깁니다. 다만 이미 출력한 바이트나 소비한 입력은 되돌릴 수 없습니다.
