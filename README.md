<p align="center"><a href="README_EN.md">English</a> / 한국어 / <a href="README_JP.md">日本語</a></p>

Yahalang은 *치이카와* 우사기의 랩 후렴에서 문법을 따온 난해한 프로그래밍 언어입니다.\
한국어, 영어, 일본어 표기로 코드를 작성합니다. 값을 스택에 쌓아 계산하며, 부호 있는 64비트 정수와 정수 배열을 다룹니다.

자세한 문법은 [DESIGN.md](DESIGN.md)에 있습니다.

## 실행

```sh
cargo build
cargo run -- run examples/hello_world.yaha --lang ko
cargo run -- run examples/countdown.yaha --lang ko
```

첫 번째 예제는 `Hello, world!`와 줄바꿈을, 두 번째 예제는 `321`을 출력합니다.\
예제 파일은 모두 한국어 표기로 작성했으므로 `--lang ko` 옵션을 붙여 실행합니다.

```sh
cargo run -- repl --lang ko
```

```text
yaha> 하야하 뿌루뿌루 야하 이이이야하 뿌루루
2
yaha> :q
```

REPL은 입력한 한 줄을 하나의 프로그램으로 실행합니다. 블록도 같은 줄에서 닫아야 합니다.\
새 줄을 입력할 때마다 스택과 배열이 초기화됩니다. `:q`나 `:quit`을 입력하면 종료합니다.\
파일로 실행하면 파일 전체가 하나의 프로그램입니다. 줄이 바뀌어도 스택과 배열의 값은 유지됩니다.\

## 숫자

숫자는 `하야하`로 시작하고 `야하`로 끝납니다. 그 사이에 넣은 `뿌루`의 개수가 숫자 값입니다.

| 코드 | 값 |
| --- | --- |
| `하야하 야하` | 0 |
| `하야하 뿌루 야하` | 1 |
| `하야하 뿌루뿌루 야하` | 2 |

숫자 안에는 공백과 줄바꿈을 넣어도 됩니다. 숫자 뒤에 `우라 얏`을 붙이면 부호가 바뀝니다.

다음 코드는 2와 3을 더해 `5`를 출력합니다.

```text
하야하 뿌루뿌루 야하
하야하 뿌루뿌루뿌루 야하
야하
이이이야하 뿌루루
얏
```

## 명령과 구절

| 한국어 | 영어 | 일본어 | 동작 |
| --- | --- | --- | --- |
| `하야하 … 야하` | `hayaha … yaha` | `ハヤハ … ヤハ` | `뿌루` 개수로 정수 생성 |
| `야하` | `yaha` | `ヤハ` | 덧셈 |
| `우라 야하` | `ura yaha` | `ウラ ヤハ` | 뺄셈 |
| `핫` | `hat` | `ハッ` | 곱셈 |
| `우라 핫` | `ura hat` | `ウラ ハッ` | 정수 나눗셈 |
| `우라 핫핫` | `ura hathat` | `ウラ ハッハッ` | 나머지 |
| `우라 얏` | `ura yat` | `ウラ ヤッ` | 부호 반전 |
| `뿌루` / `우라 뿌루` | `ppuru` / `ura ppuru` | `プル` / `ウラ プル` | 복제 / 버리기 |
| `이이이야하` | `iiiiyaha` | `イイイヤハ` | 정수 입력 |
| `이이이야하 뿌루루` | `iiiiyaha ppururu` | `イイイヤハ プルル` | 정수 출력 |
| `이이이야하 우라라` | `iiiiyaha urara` | `イイイヤハ ウララ` | 유니코드 문자 출력 |
| `얏` | `yat` | `ヤッ` | 프로그램 종료 |

사칙연산은 스택 맨 위의 정수 두 개를 꺼내 계산합니다. 아래에 있던 값이 왼쪽 피연산자입니다. 7을 넣고 2를 넣은 뒤 뺄셈을 실행하면 5가 남습니다.\
나눗셈은 소수점 아래를 버립니다. 예를 들어 -7을 2로 나누면 -3입니다.\
입력 명령은 한 줄에 정수 하나를 읽습니다. 출력 명령은 스택에서 값을 꺼내 출력하며, 줄바꿈을 붙이지 않습니다.

소리는 `이야`, `우라`처럼 씁니다. 대시를 넣거나 정해지지 않은 소리를 쓰면 오류가 납니다.\
`야하야하`, `뿌루뿌루`, `핫핫핫`처럼 붙여 써도 됩니다. 소리가 겹치면 긴 쪽을 먼저 읽습니다.\
`뿌루루`는 `뿌루`와 다른 소리로 읽습니다.\
공백과 줄바꿈은 구절을 끊지 않습니다. `이이이야하` 다음 줄에 `뿌루루`를 써도 하나의 정수 출력 명령으로 읽습니다.

명령을 명확히 구분하려면 `;`를 넣습니다.

- `우라 야하야하`: 조건 블록 닫기
- `우라 야하 ; 야하`: 뺄셈 후 덧셈
- `야하야하`: 덧셈 두 번

숫자나 블록을 여닫는 구절 중간에는 `;`를 넣을 수 없습니다.\
문자열이나 문자를 직접 적는 문법과 주석 문법은 아직 없습니다.

## 반복과 조건

| 시작 | 끝 | 동작 |
| --- | --- | --- |
| `이야 야다야다` | `우라 야다야다` | 맨 위 정수가 0이 아닌 동안 반복 |
| `이야 야하야하` | `우라 야하야하` | 정수를 꺼내 0이 아니면 본문 실행 |

반복문은 본문 실행 전과 매 반복이 끝날 때 스택 맨 위의 정수가 0인지 확인합니다. 검사한 값은 스택에 그대로 남습니다.\
반복문 본문에는 다음 검사에 쓸 정수 하나를 남겨야 합니다. 블록은 최대 128단계까지 중첩됩니다.

```text
하야하 뿌루뿌루뿌루 야하
이야 야다야다
    뿌루
    이이이야하 뿌루루
    하야하 뿌루 야하
    우라 야하
우라 야다야다
얏
```

실행하면 `321`이 나오고, 빈 줄과 들여쓰기는 자유롭게 넣어도 됩니다.

## 입력

```text
이이이야하
이이이야하
야하
이이이야하 뿌루루
얏
```

```sh
printf '12\n30\n' | cargo run -- run examples/add_two_numbers.yaha --lang ko
```

숫자마다 줄을 나눠 입력하면 `42`가 나오지만, `12 30`을 한 줄에 넣으면 오류가 납니다.

## 배열

```text
[하야하 야하, 하야하 뿌루 야하, 하야하 뿌루뿌루 야하]
하야하 뿌루 야하 @
이이이야하 뿌루루
```

위 코드는 `[0, 1, 2]` 배열을 만들고 두 번째 원소를 출력합니다. 인덱스는 0부터 시작하므로 출력값은 `1`입니다.\
빈 배열은 `[]`로 만듭니다. 배열 안에 배열을 넣는 문법은 지원하지 않습니다.

| 명령 | 피연산자: 스택 아래에서 위로 | 동작 |
| --- | --- | --- |
| `#` | 배열 | 길이 조회 |
| `@` | 배열, 인덱스 | 정수 조회 |
| `=` | 배열, 인덱스, 값 | 원소 수정 |

배열 명령은 피연산자를 모두 스택에서 꺼냅니다. 같은 배열을 다시 쓰려면 명령 실행 전에 `뿌루`로 배열 참조를 복제합니다.\
두 참조는 같은 배열을 가리킵니다. 어느 쪽에서 원소를 수정해도 함께 바뀝니다.

## 언어 설정과 오류

`run`과 `repl`에서 `--lang ko`, `--lang en`, `--lang ja`로 코드의 언어 표기를 선택합니다. 한 프로그램 안에서는 같은 표기를 사용합니다.\
자주 쓰는 표기는 아래 명령으로 기본값을 저장합니다. 실행할 때 지정한 `--lang`이 저장된 설정보다 우선합니다. 둘 다 없으면 영어 표기를 사용합니다.

```sh
cargo run -- set lang ko
```

설정 파일에는 `lang = "ko"` 형식으로 저장합니다. 운영체제별 경로는 다음과 같습니다.

- Linux: `$XDG_CONFIG_HOME/yahalang/config.toml` 또는 `~/.config/yahalang/config.toml`
- macOS: `~/Library/Application Support/yahalang/config.toml`
- Windows: `%APPDATA%/yahalang/config.toml`

기본 오류 메시지는 우사기 말소리로 나오고, `friendly`를 붙이면 원인을 표시합니다.

```sh
cargo run -- repl --lang ko --error-style friendly
```

실행 중에는 스택 값 부족, 맞지 않는 타입, 잘못된 입력이나 배열 인덱스, 유효하지 않은 문자 코드, 정수 범위를 넘는 계산, 0으로 나누기가 오류의 원인이 됩니다.\
닫지 않은 숫자나 블록, 잘못 쓴 구절은 실행 전에 검사합니다. `friendly` 오류 메시지에 표시된 줄 번호로 위치를 확인합니다.
