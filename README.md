<h1 align="center">Yahalang</h1>

<p align="center"><img src="image.png" alt="치이카와의 우사기" width="280"></p>
<p align="center"><a href="README_EN.md">English</a> / 한국어 / <a href="README_JP.md">日本語</a></p>

Yahalang은 *치이카와* 우사기의 우사기랩 후렴을 언어의 문법으로 옮겼습니다.\
한국어, 영어, 일본어로 작성하며, 값을 스택에 쌓아 계산하고 부호 있는 64비트 정수와 정수 배열을 다룹니다.

자세한 문법은 [DESIGN.md](DESIGN.md)에 있습니다.

## 실행

```sh
cargo build
cargo run -- run examples/hello_world.yaha --lang ko
cargo run -- run examples/countdown.yaha --lang ko
```

첫 번째 예제는 `Hello, world!`를 출력하고, 두 번째는 `321`을 출력합니다.\
예제는 모두 한국어로 작성했기 때문에 실행할 때 `--lang ko` 옵션을 붙여야 합니다.

```sh
cargo run -- repl --lang ko
```

```text
yaha> 하야하 뿌루뿌루 야하 이이이야하 뿌루루
2
yaha> :q
```

REPL은 한 줄을 프로그램 하나로 실행하기 때문에, 블록도 같은 줄 안에서 닫아야 합니다.\
다음 입력에서는 스택과 배열이 초기화되고, `:q`나 `:quit`을 입력하면 종료합니다.\
파일 전체는 하나의 프로그램이라서 줄이 바뀌어도 값이 유지됩니다.

## 숫자

숫자는 `하야하`로 시작해서 `야하`로 끝내며, 그 사이에 `뿌루`를 넣은 만큼 커집니다.

| 코드 | 값 |
| --- | --- |
| `하야하 야하` | 0 |
| `하야하 뿌루 야하` | 1 |
| `하야하 뿌루뿌루 야하` | 2 |

숫자 안에서는 띄어쓰거나 줄을 바꿔도 되고, 음수는 숫자 뒤에 `우라 얏`을 붙여 만듭니다.\
다음 코드는 2와 3을 더해 `5`를 출력합니다.

```text
하야하 뿌루뿌루 야하
하야하 뿌루뿌루뿌루 야하
야하
이이이야하 뿌루루
얏
```

## 명령과 구절

| 한국어 | 영어 | 일본어 | 동작 |
| --- | --- | --- | --- |
| `하야하 … 야하` | `hayaha … yaha` | `ハヤハ … ヤハ` | `뿌루` 개수로 정수 생성 |
| `야하` | `yaha` | `ヤハ` | 덧셈 |
| `우라 야하` | `ura yaha` | `ウラ ヤハ` | 뺄셈 |
| `핫` | `hat` | `ハッ` | 곱셈 |
| `우라 핫` | `ura hat` | `ウラ ハッ` | 정수 나눗셈 |
| `우라 핫핫` | `ura hathat` | `ウラ ハッハッ` | 나머지 |
| `우라 얏` | `ura yat` | `ウラ ヤッ` | 부호 반전 |
| `뿌루` / `우라 뿌루` | `ppuru` / `ura ppuru` | `プル` / `ウラ プル` | 복제 / 버리기 |
| `이이이야하` | `iiiiyaha` | `イイイヤハ` | 정수 입력 |
| `이이이야하 뿌루루` | `iiiiyaha ppururu` | `イイイヤハ プルル` | 정수 출력 |
| `이이이야하 우라라` | `iiiiyaha urara` | `イイイヤハ ウララ` | 유니코드 문자 출력 |
| `얏` | `yat` | `ヤッ` | 프로그램 종료 |

계산은 스택 맨 위의 두 값을 꺼내 아래 값을 왼쪽에 놓기에, 7 위에 2를 쌓고 빼면 5가 됩니다.\
나눗셈은 소수점 아래를 버려서 -7을 2로 나누면 -3이 됩니다.\
입력은 한 줄에 정수 하나씩 받고, 출력할 때는 값을 스택에서 꺼내되 줄바꿈은 따로 붙이지 않습니다.

소리는 대시 없이 `이야`, `우라`처럼 쓰며, 대시를 넣거나 정해지지 않은 소리를 쓰면 오류가 납니다.\
`야하야하`, `뿌루뿌루`, `핫핫핫`처럼 붙여 써도 되고, 소리가 겹칠 때는 긴 쪽을 먼저 읽습니다.\
`뿌루루`는 `뿌루`와 다른 소리로 읽습니다.\
공백과 줄바꿈은 구절을 끊지 않아서 `이이이야하` 다음 줄에 `뿌루루`를 써도 정수 출력으로 읽습니다.

명령은 `;`로 구분합니다.\
`우라 야하야하`는 조건 블록을 닫지만, `우라 야하 ; 야하`는 뺄셈을 한 뒤 덧셈을 하고, `야하야하`만 쓰면 덧셈을 두 번 합니다.\
숫자나 블록을 여닫는 구절 중간에는 `;`를 넣을 수 없습니다.\
문자열이나 문자를 직접 적는 문법과 주석 문법은 아직 없습니다.

## 반복과 조건

| 시작 | 끝 | 동작 |
| --- | --- | --- |
| `이야 야다야다` | `우라 야다야다` | 맨 위 정수가 0이 아닌 동안 반복 |
| `이야 야하야하` | `우라 야하야하` | 정수를 꺼내 0이 아니면 본문 실행 |

반복문은 맨 위 값을 그대로 둔 상태로, 시작할 때와 한 번 돌 때마다 0인지 확인합니다.\
다음 검사를 위해 반복문 안에서 정수 하나를 남겨야 하고, 블록은 최대 128단계까지 중첩됩니다.

```text
하야하 뿌루뿌루뿌루 야하
이야 야다야다
    뿌루
    이이이야하 뿌루루
    하야하 뿌루 야하
    우라 야하
우라 야다야다
얏
```

실행하면 `321`이 나오고, 빈 줄과 들여쓰기는 자유롭게 넣어도 됩니다.

## 입력

```text
이이이야하
이이이야하
야하
이이이야하 뿌루루
얏
```

```sh
printf '12\n30\n' | cargo run -- run examples/add_two_numbers.yaha --lang ko
```

숫자마다 줄을 나눠 입력하면 `42`가 나오지만, `12 30`을 한 줄에 넣으면 오류가 납니다.

## 배열

```text
[하야하 야하, 하야하 뿌루 야하, 하야하 뿌루뿌루 야하]
하야하 뿌루 야하 @
이이이야하 뿌루루
```

`[0, 1, 2]`를 만들고 두 번째 값을 읽는 예제로, 인덱스는 0부터 세므로 결과는 `1`입니다.\
빈 배열은 `[]`로 만들지만, 배열 안에 배열은 넣지 못합니다.

| 명령 | 피연산자: 스택 아래에서 위로 | 동작 |
| --- | --- | --- |
| `#` | 배열 | 길이 조회 |
| `@` | 배열, 인덱스 | 정수 조회 |
| `=` | 배열, 인덱스, 값 | 원소 수정 |

위 명령은 값을 스택에서 꺼내 쓰기에, 같은 배열을 다시 쓰려면 먼저 `뿌루`로 참조를 복제합니다.\
참조만 복제하기 때문에 어느 쪽으로 수정하든 같은 배열에 반영됩니다.

## 언어 설정과 오류

`run`과 `repl`의 표기는 `--lang ko`, `--lang en`, `--lang ja`로 고르고, 한 프로그램 안에서는 같은 표기를 써야 합니다.\
기본 표기는 아래처럼 저장하고, 실행 시 `--lang`을 우선하고 설정이 없으면 영어를 씁니다.

```sh
cargo run -- set lang ko
```

설정은 `lang = "ko"`처럼 저장되고, 운영체제별 파일 위치는 다음과 같습니다.

- Linux: `$XDG_CONFIG_HOME/yahalang/config.toml` 또는 `~/.config/yahalang/config.toml`
- macOS: `~/Library/Application Support/yahalang/config.toml`
- Windows: `%APPDATA%/yahalang/config.toml`

기본 오류 메시지는 우사기 말소리로 나오고, `friendly`를 붙이면 원인을 표시합니다.

```sh
cargo run -- repl --lang ko --error-style friendly
```

실행 중에는 스택 값 부족, 맞지 않는 타입, 잘못된 입력이나 배열 인덱스, 유효하지 않은 문자 코드, 정수 범위를 넘는 계산, 0으로 나누기가 오류의 원인이 됩니다.\
숫자나 블록을 닫지 않았거나 구절을 잘못 쓰면 실행 전에 오류를 표시하고, `friendly` 메시지의 줄 번호로 위치를 확인합니다.

## 테스트와 릴리스

```sh
cargo fmt --check
cargo test --release
```

GitHub Actions는 포맷을 검사하고 release 테스트를 돌린 뒤, Linux x86-64, Windows x86-64, macOS Apple Silicon용 빌드 파일을 만듭니다.\
PR을 열거나 `master`와 버전 태그를 푸시하면 실행되며, 수동 실행도 가능합니다.\
릴리스는 Cargo.toml과 Cargo.lock의 버전을 맞추고 `v1.0.0`처럼 같은 버전의 태그를 푸시해 배포합니다.\
빌드가 끝나면 운영체제별 압축 파일과 `SHA256SUMS`가 릴리스에 올라갑니다.\
사전 배포 버전의 태그는 프리릴리스로 올라가고, 수동 실행에서는 릴리스를 만들지 않고 빌드 결과만 남깁니다.
