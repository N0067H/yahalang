# 대표 프로그램

Yahalang의 현재 명령만으로 작성한 알고리즘·문자열 처리 예제입니다. 모두 한국어 표기이며, 저장소 루트에서 다음처럼 실행합니다.

```sh
cargo run -- run examples/gcd.yaha --lang ko
```

숫자는 한 줄에 하나씩 입력합니다. 결과도 한 줄에 하나씩 출력합니다. 입력은 표준 입력으로 전달하므로 파일이나 파이프도 사용할 수 있습니다.

```sh
printf '48\n18\n' | cargo run -- run examples/gcd.yaha --lang ko
```

## 목록

| 순서 | 프로그램 | 입력 | 출력 |
| --- | --- | --- | --- |
| 1 | [팩토리얼](factorial.yaha) | 정수 N | N! |
| 2 | [최대공약수](gcd.yaha) | 음이 아닌 정수 2개 | 최대공약수 |
| 3 | [피보나치 수열](fibonacci.yaha) | 항의 개수 N | 0부터 시작하는 N개 항 |
| 4 | [소수 판별](is_prime.yaha) | 정수 N | 소수이면 1, 아니면 0 |
| 5 | [숫자 통계](number_stats.yaha) | 개수 N, 정수 N개 | 합, 최솟값, 최댓값 |
| 6 | [배열 정렬](array_sort.yaha) | 개수 N, 정수 N개 | 오름차순으로 정렬한 값 |
| 7 | [회문 판별](palindrome.yaha) | 문자열 한 줄 | 회문이면 1, 아니면 0 |
| 8 | [문자 빈도](character_frequency.yaha) | 문자열 한 줄, 찾을 문자 | 해당 문자의 개수 |
| 9 | [시저 암호](caesar_cipher.yaha) | 문자열 한 줄, 이동량 | 변환한 문자열 |
| 10 | [후위 표기 계산기](postfix_calculator.yaha) | 후위 표기식 한 줄 | 계산 결과 |

## 코드를 읽는 방법

중간값을 이름으로 저장하는 문법은 아직 없습니다. 이 예제들은 작업용 정수 배열의 칸을 변수처럼 사용합니다. 아래 각 프로그램의 표에 칸 번호와 역할을 적었습니다. 이름은 설명용이며 실제 소스에 쓰는 문법은 아닙니다.

대부분의 계산은 작업용 배열 참조 하나를 스택에 남긴 채 수행합니다. 필요한 값을 읽을 때 참조를 복제하고, 계산 결과는 다시 해당 칸에 저장합니다. 배열 참조를 자주 복제하는 이유는 조회·수정 명령이 피연산자를 소비하기 때문입니다.

숫자 예제는 배열 앞부분에 중간값을 둡니다. 통계·정렬의 입력 데이터는 그 뒤에 이어집니다. 문자열 예제는 입력 문자열의 코드 포인트 뒤에 작업용 칸을 추가합니다. 따라서 문자열의 작업용 칸은 `전체 배열 길이 - 작업용 칸 수`부터 시작합니다.

긴 계산식은 여러 줄로 나누었습니다. 줄바꿈은 명령 경계를 만들지 않습니다. 후위 표기 계산기의 `;`는 뺄셈 뒤 덧셈이 조건 블록 닫기로 합쳐지는 것을 막기 위해 남겨 둔 구분자입니다.

### 오류와 입력 범위

음수 개수 등 각 프로그램에서 거부하는 입력은 `-1`을 출력하고 끝냅니다. 소수 판별은 음수를 소수가 아닌 것으로 처리합니다. EOF·잘못된 정수·0으로 나누기·산술 오버플로는 인터프리터의 실행 오류로 처리합니다. 원인을 보려면 `--error-style friendly`를 붙입니다.

문자열은 유니코드 코드 포인트 단위로 처리합니다. 대소문자 변환이나 유니코드 정규화는 자동으로 하지 않습니다. 한 줄 입력은 끝의 LF·CRLF를 제외하며, 최대 길이는 1 MiB입니다.

## 1. 팩토리얼

```sh
printf '5\n' | cargo run -- run examples/factorial.yaha --lang ko
```

출력:

```text
120
```

누적값을 1로 시작해 N부터 2까지 곱합니다. 0!과 1!은 1입니다. 음수는 -1을 출력합니다. 64비트 정수로 표현할 수 있는 최대 입력은 20이며, 21부터는 계산 중 오버플로 오류가 납니다.

| 칸 | 역할 |
| --- | --- |
| 0 | 남은 곱셈 대상 N |
| 1 | 누적 결과 |

## 2. 최대공약수

```sh
printf '48\n18\n' | cargo run -- run examples/gcd.yaha --lang ko
```

출력:

```text
6
```

유클리드 호제법을 사용합니다. b가 0이 될 때까지 나머지를 구하고 `(a, b)`를 `(b, a % b)`로 바꿉니다. 음수 입력은 -1을 출력합니다. 두 입력이 모두 0이면 이 예제에서는 0을 반환합니다.

| 칸 | 역할 |
| --- | --- |
| 0 | a |
| 1 | b |
| 2 | 나머지 |

## 3. 피보나치 수열

```sh
printf '7\n' | cargo run -- run examples/fibonacci.yaha --lang ko
```

출력:

```text
0
1
1
2
3
5
8
```

0부터 시작해 N개 항을 출력합니다. N이 0이면 아무것도 출력하지 않습니다. 지원 범위는 0부터 93까지이고, 그 밖의 입력은 -1을 출력합니다. 마지막 항 이후의 덧셈을 생략해 F92인 7540113804746346429까지 출력할 수 있습니다.

| 칸 | 역할 |
| --- | --- |
| 0 | 출력할 항의 개수 N |
| 1 | 이전 항 |
| 2 | 현재 항 |
| 3 | 다음 항을 계산하는 임시값 |
| 4 | 현재 항 번호 |

## 4. 소수 판별

```sh
printf '97\n' | cargo run -- run examples/is_prime.yaha --lang ko
```

출력:

```text
1
```

2부터 시험 나눗셈을 하고 약수를 찾으면 `우라 이야`로 반복을 끝냅니다. 2 미만은 0을 출력합니다. 반복 범위는 `divisor <= N / divisor`로 검사해 제곱 계산의 오버플로를 피합니다. 큰 소수는 검사할 약수가 많아 오래 걸릴 수 있습니다.

| 칸 | 역할 |
| --- | --- |
| 0 | 입력 N |
| 1 | 검사 중인 약수 |
| 2 | 소수 여부 |

## 5. 숫자 통계

```sh
printf '5\n3\n-2\n7\n7\n0\n' | cargo run -- run examples/number_stats.yaha --lang ko
```

출력:

```text
15
-2
7
```

입력한 정수들을 배열에 저장하고 다시 순회해 합·최솟값·최댓값을 구합니다. 세 결과를 이 순서로 출력합니다. N은 1 이상이어야 하며, 0이나 음수이면 -1을 출력합니다. 합을 구하는 도중 정수 범위를 벗어나면 실행 오류입니다.

| 칸 | 역할 |
| --- | --- |
| 0 | 입력 개수 N |
| 1 | 입력·순회 인덱스 |
| 2 | 현재 값 |
| 3 | 합 |
| 4 | 최솟값 |
| 5 | 최댓값 |
| 6 이후 | 입력 데이터 |

## 6. 배열 정렬

```sh
printf '5\n3\n-2\n7\n3\n0\n' | cargo run -- run examples/array_sort.yaha --lang ko
```

출력:

```text
-2
0
3
3
7
```

입력 배열을 `야다 우라라`로 복사하고 복사본에서 버블 정렬을 수행합니다. 이웃한 두 값을 비교해 순서가 반대면 바꾸며, 한 번도 교환하지 않은 순회 뒤에는 멈춥니다. 실행이 끝나면 원본 작업 배열은 스택에 남고 정렬한 복사본은 버립니다.

N이 0이면 출력 없이 끝나고, 음수이면 -1을 출력합니다. 중복값과 음수도 정렬합니다.

| 칸 | 역할 |
| --- | --- |
| 0 | 입력 개수 N |
| 1 | 정렬할 구간의 끝, 입력·출력 인덱스 |
| 2 | 이웃한 원소를 비교하는 인덱스 |
| 3 | 왼쪽 원소 |
| 4 | 오른쪽 원소 |
| 5 | 이번 순회의 교환 여부 |
| 6 이후 | 입력 데이터 |

## 7. 회문 판별

```sh
printf '토마토\n' | cargo run -- run examples/palindrome.yaha --lang ko
```

출력:

```text
1
```

문자열 양끝에서 가운데로 이동하며 코드 포인트를 비교합니다. 다른 값을 만나면 반복을 끝냅니다. 빈 문자열과 한 글자도 회문으로 처리합니다. 공백·대소문자를 포함해 정확히 비교하므로 `Racecar`는 0입니다.

입력 문자열 바로 뒤의 작업용 칸은 다음 순서입니다.

| 상대 칸 | 역할 |
| --- | --- |
| 0 | 문자열 길이 N |
| 1 | 왼쪽 인덱스 |
| 2 | 오른쪽 인덱스 |
| 3 | 현재까지 일치하는지 여부 |

## 8. 문자 빈도 집계

```sh
printf 'banana\na\n' | cargo run -- run examples/character_frequency.yaha --lang ko
```

출력:

```text
3
```

첫 줄은 검색할 문자열, 그다음 입력은 찾을 문자 하나입니다. 해당 문자의 코드 포인트와 같은 원소를 셉니다. 공백·NUL도 검색할 수 있습니다. 찾을 문자를 읽기 전에 EOF이면 -1을 출력합니다. 문자 입력은 한 문자만 소비하므로 뒤의 줄바꿈은 읽지 않습니다.

입력 문자열 뒤에 다음 칸을 둡니다.

| 상대 칸 | 역할 |
| --- | --- |
| 0 | 문자열 길이 N |
| 1 | 검색 인덱스 |
| 2 | 찾을 코드 포인트 |
| 3 | 개수 |

## 9. 시저 암호

```sh
printf 'Abc Z!\n2\n' | cargo run -- run examples/caesar_cipher.yaha --lang ko
```

출력:

```text
Cde B!
```

첫 줄은 문자열, 둘째 줄은 이동량입니다. 영문 대문자·소문자를 각각 알파벳 안에서 순환시키며, 다른 문자는 그대로 둡니다. 음수 이동량은 반대 방향이고, 26의 배수만큼 이동하면 원래 문자열이 됩니다.

복호화하려면 이동량의 부호를 바꿉니다.

```sh
printf 'Cde B!\n-2\n' | cargo run -- run examples/caesar_cipher.yaha --lang ko
```

출력은 `Abc Z!`입니다. 이동량을 먼저 0부터 25까지로 정규화하므로 64비트 정수의 최솟값도 처리합니다. 결과 뒤에는 줄바꿈 하나를 출력합니다.

입력 문자열 뒤에 다음 칸을 둡니다.

| 상대 칸 | 역할 |
| --- | --- |
| 0 | 문자열 길이 N |
| 1 | 현재 인덱스 |
| 2 | 정규화한 이동량 |
| 3 | 현재 코드 포인트 |
| 4 | 영문 대문자·소문자 범위의 시작값 |

## 10. 후위 표기 계산기

```sh
printf '12 3 + 2 *\n' | cargo run -- run examples/postfix_calculator.yaha --lang ko
```

출력:

```text
30
```

연산자를 두 피연산자 뒤에 쓰는 계산기입니다. 위 식은 `(12 + 3) * 2`를 뜻합니다. `+`, `-`, `*`, `/`, `%`는 계산기에 전달하는 입력 데이터이며 Yahalang의 명령이 아닙니다.

- 토큰은 공백이나 탭으로 구분합니다.
- 정수는 여러 자리로 쓸 수 있고 음수에는 `-`를 붙입니다. `+3` 형태는 받지 않습니다.
- 연산자는 값 두 개를 꺼내 계산합니다. 먼저 들어간 값이 왼쪽입니다.
- 정수 범위는 부호 있는 64비트이며 나눗셈은 0 방향으로 버립니다.
- 피연산자 부족, 남은 값이 여러 개, 알 수 없는 토큰, 빈 식은 -1을 출력합니다. 정상 계산 결과 -1과 출력으로 구별되지는 않습니다.
- 0으로 나누기와 숫자 파싱·계산 중 오버플로는 인터프리터의 실행 오류로 남깁니다.

예를 들어 `-7 2 /`는 -3, `8 3 -`는 5입니다. `1 +`, `1 2`, `12+`는 잘못된 식입니다.

원본 문자열의 길이가 N이면 그 뒤에 N개의 계산 스택 칸을 확보하고, 마지막에 작업용 칸을 붙입니다. 입력 문자를 덮어쓰지 않고 계산값을 저장하기 위한 배치입니다. 숫자를 읽는 반복과 연산자 처리를 나누고, 마지막에는 계산 스택에 값이 정확히 하나인지 확인합니다.

| 작업용 상대 칸 | 역할 |
| --- | --- |
| 0 | 입력 길이 N |
| 1 | 읽는 위치 |
| 2 | 계산 스택의 원소 수 |
| 3 | 현재 문자 |
| 4 | 파싱 중인 정수 |
| 5 | 정수의 부호 |
| 6 | 숫자를 읽었는지 여부 |
| 7 | 음수 부호인지 여부 |
| 8 | 다음 문자 확인용 임시값 |
| 9 | 연산자 코드 포인트 |
| 10 | 오른쪽 피연산자 |
| 11 | 왼쪽 피연산자 |
| 12 | 계산 결과 |
| 13 | 식의 유효성 |
