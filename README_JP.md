<h1 align="center">Yahalang</h1>

<p align="center"><img src="image.png" alt="ちいかわのうさぎ" width="280"></p>
<p align="center"><a href="README_EN.md">English</a> / <a href="README.md">한국어</a> / 日本語</p>

Yahalang は『ちいかわ』のうさぎラップのフレーズを文法にした、うさぎの声でコードを書けるスタック型の難解プログラミング言語です。\
韓国語、英語、日本語から好きな表記を選び、値をスタックに積んで計算する仕組みで符号付き64ビット整数と整数配列を扱えます。

以前のバージョンから文法が変わり、`ura yaha` で数を作る書き方や `ui` による入力、行番号ジャンプは使えなくなっています。\
以前のコードは、下のサンプルを参考に書き直してください。

## 実行

```sh
cargo build
cargo run -- run examples/hello_world.yaha --lang ko
cargo run -- run examples/countdown.yaha --lang ko
cargo run -- repl --lang ja
```

韓国語で書かれたサンプルファイルを `--lang ko` で実行すると、最初のサンプルは `Hello, world!` と改行、次のサンプルは `321` を出力します。\
REPL は入力の間もスタックと配列を保持します。未完成のブロックや数値は `...>` で入力を続け、完成すると実行します。
`:stack` はスタックを下から上へ表示し、`:reset` はスタックと入力中のコードを消去します。`:q` または `:quit` で終了します。
構文エラーでは入力中のコードを破棄し、実行時エラーではエラーまでの変更を保持します。`ヤッ` は現在のコードの実行だけを終了します。EOF では未完成のコードをエラーとして表示します。

## 数値と命令

数は `ハヤハ` で始め、`プル` を数の分だけ並べて `ヤハ` で終えます。\
`プル` がなければ0、2個なら2になり、途中に空白や改行を入れても値は変わりません。

| 日本語 | 韓国語 | 英語 | 動作 |
| --- | --- | --- | --- |
| `ハヤハ … ヤハ` | `하야하 … 야하` | `hayaha … yaha` | 整数リテラル |
| `ヤハ` | `야하` | `yaha` | 加算 |
| `ウラ ヤハ` | `우라 야하` | `ura yaha` | 減算 |
| `ハッ` | `핫` | `hat` | 乗算 |
| `ウラ ハッ` | `우라 핫` | `ura hat` | 整数除算（0方向に丸める） |
| `ウラ ハッハッ` | `우라 핫핫` | `ura hathat` | 剰余 |
| `ウラ ヤッ` | `우라 얏` | `ura yat` | 符号反転 |
| `プル` / `ウラ プル` | `뿌루` / `우라 뿌루` | `ppuru` / `ura ppuru` | 複製 / 破棄 |
| `イヤ プル` | `이야 뿌루` | `iya ppuru` | スタックの先頭2つの値を交換 |
| `イイイヤハ` | `이이이야하` | `iiiiyaha` | 整数入力 |
| `ウララ イイイヤハ` | `우라라 이이이야하` | `urara iiiiyaha` | 文字入力、EOF は -1 |
| `イイイヤハ プルル` | `이이이야하 뿌루루` | `iiiiyaha ppururu` | 整数出力 |
| `イイイヤハ ウララ` | `이이이야하 우라라` | `iiiiyaha urara` | Unicode文字出力 |
| `ヤッ` | `얏` | `yat` | 終了 |

計算にはスタックの一番上の値を2個使い、下にある値が左側になるので、7の上に2を積んで引くと5になります。\
出力した値はスタックから取り出され、改行は付きません。\
入力は1行に整数を1個ずつ入れてください。\
ここでの日本語と英語の表記はコード用に決めたもので、公式の歌詞表記ではありません。

## フレーズとブロック

音は `イヤ` や `ウラ` のように、ダッシュを入れずに書いてください。\
`プルプル` のようにつなげて書いても大丈夫ですが、音が重なるときは長い方を先に読むので、`プルル` は `プル` とは別の音になります。\
空白や改行を入れてもフレーズは続くので、`イイイヤハ` の次の行に `プルル` を書いても、まとめて整数出力として読みます。

命令を分けたいときは `;` を挟むと、条件ブロックを閉じる `ウラ ヤハヤハ` と区別して、`ウラ ヤハ ; ヤハ` で引き算の後に足し算ができます。\
`ヤハヤハ` だけなら足し算を2回します。\
数やブロックを開閉するフレーズの途中には `;` を入れないでください。\
文字列や文字を直接書く文法と、コメントの文法はまだありません。

| 開始 | 終了 | 動作 |
| --- | --- | --- |
| `イヤ ヤダヤダ` | `ウラ ヤダヤダ` | 先頭の整数が0でない間、繰り返す |
| `イヤ ヤハヤハ` | `ウラ ヤハヤハ` | 整数を取り出し、0でなければ本体を実行 |

ループは一番上の値を取り出さずに開始時と1周するたびに0かどうかを確かめるので、次の確認用に整数をひとつ残してください。\
ブロックは128段まで入れ子にでき、空行やインデントは自由です。

```text
ハヤハ プルプルプル ヤハ
イヤ ヤダヤダ
    プル
    イイイヤハ プルル
    ハヤハ プル ヤハ
    ウラ ヤハ
ウラ ヤダヤダ
ヤッ
```

上のループは `321` を出力し、次のコードは整数を2個入力して足します。

```text
イイイヤハ
イイイヤハ
ヤハ
イイイヤハ プルル
ヤッ
```

## 配列

```text
[ハヤハ ヤハ, ハヤハ プル ヤハ, ハヤハ プルプル ヤハ]
ハヤハ プル ヤハ @
イイイヤハ プルル
```

添字は0から数えるので、`[0, 1, 2]` の2番目の値を読むと `1` が出力されます。\
空の配列は `[]` で作れますが、配列の中に配列は入れられません。\
長さを調べる `#` は配列を、値を読む `@` は配列と添字をスタックから取り出して使います。\
値を変えるには配列、添字、新しい整数値の順に積んで `=` を使い、これらの値もスタックから取り出します。\
同じ配列を再利用するには `プル` で参照を複製し、配列そのものは共有するため、どちらから変更しても反映されます。

## 設定とエラー

`run` と `repl` は `--lang en|ko|ja`、`--error-style usagi|friendly` に対応します。\
明示した言語オプションが保存設定より優先され、両方ない場合は英語です。\
既定値は `cargo run -- set lang ja` で保存できます。\
設定は `lang = "ja"` 形式の TOML で、Linux では `$XDG_CONFIG_HOME/yahalang/config.toml`\
（未設定時は `~/.config/yahalang/config.toml`）、macOS では `~/Library/Application Support/yahalang/config.toml`、\
Windows では `%APPDATA%/yahalang/config.toml` に保存されます。

エラーはうさぎの声で表示し、`--error-style friendly` を付けると理由とソースの位置も表示します。\
実行が止まったら、スタックの値不足や型違い、整数の範囲を超える計算、0で割る計算、不正な入力や添字、Unicode値がないか確認してください。\
数やブロックの閉じ忘れ、決められていない音は、実行する前にエラーで知らせます。

## サンプルとテスト

[examples](examples) に Hello World、加算、整数エコー、配列変更、カウントダウン、truth machine があります。\
どれも `--lang ko` で実行でき、truth machine には0か1を入力します。\
1を入れると出力が続くので、止めるときは Ctrl-C を押してください。

```sh
cargo fmt --check
cargo test --release
```

GitHub Actions は書式、releaseテストを検査し、Linux x86-64、Windows x86-64、macOS Apple Silicon 用バイナリを作成します。\
リリースを公開するときは Cargo.toml と Cargo.lock のバージョンをそろえて、`v1.0.0` のように同じバージョンのタグをプッシュしてください。\
リリースには圧縮ファイルと `SHA256SUMS` が添付され、プレリリースタグはプレリリースとなりますが、手動実行ではビルドファイルだけが作られます。

## 文字入力

`ウララ イイイヤハ` は UTF-8 の Unicode スカラーを1つ読み、コードポイントをスタックに積みます。空白、改行、NUL も読みます。EOF では -1、不正または途中で切れた UTF-8 は実行時エラーになります。文字出力 `イイイヤハ ウララ` とは逆の語順です。

`yahalang run examples/character_echo.yaha --lang ko` で EOF まで入力をそのまま出力します。サンプルはコードポイントに1を足して繰り返し条件を調べ、NUL も出力して -1 で終了します。

整数入力や REPL と同じ入力ストリームを使い、後続の文字や改行を消費しません。端末では Enter が必要な場合があり、その改行は次の入力に残ります。

## 配列の追加と取り出し

| 命令 | スタックの変化（下から上） |
| --- | --- |
| `ヤダ ハヤハ` | 新しい空の配列をスタックに積む |
| `ヤダ プル` | 配列、整数 → 配列。末尾に整数を追加 |
| `ヤダ ウラ` | 配列 → 配列、整数。末尾の整数を取り出す |
| `ヤダ ウララ` | 配列 → 元の配列、独立したコピー |
| `ヤダ プルル` | 配列 → 長さ |
| `ヤダ イヤ` | 配列、添字 → 要素 |
| `ヤダ ハッ` | 配列、添字、値 → 引数を消費して要素を変更 |

`ヤダ ハヤハ` は実行のたびに独立した空の配列を作り、末尾の `ヤハ` は不要です。従来の配列リテラルも使えます。

追加と取り出しは配列参照をスタックに残し、共有配列を変更します。空の配列からの取り出し、型の不一致、スタック不足は実行時エラーになり、スタックと配列を変更しません。命令内の改行は使えますが、`;` は入れられません。

```text
ヤダ ハヤハ
ハヤハ プル ヤハ
ヤダ プル
ハヤハ プルプル ヤハ
ヤダ プル
ヤダ ウラ
イイイヤハ プルル
ヤダ ウラ
イイイヤハ プルル
```

1、2の順に追加し、逆順に取り出して `21` を出力します。

```sh
printf 'abc' | yahalang run examples/reverse_input.yaha --lang ko
```

出力は `cba` です。EOF まで読み込んだ Unicode スカラーを逆順に出力し、改行も反転します。結合文字列はひとまとまりとして扱いません。

`ヤダ プルル`、`ヤダ イヤ`、`ヤダ ハッ` はそれぞれ `#`、`@`、`=` と同じ動作で、配列参照を消費します。再利用する場合は先に参照を複製してください。従来の記号も使えます。

## 繰り返しから抜ける

`ウラ イヤ` は最も内側の繰り返しから抜け、終了句の次へ進みます。条件ブロックの中でも使えます。スタックは変更せず、`ヤッ` と異なりプログラム全体を終了しません。繰り返しの外では実行前の構文エラーになります。句の途中の改行は使えますが、`;` は入れられません。

```text
ハヤハ プルプルプル ヤハ
イヤ ヤダヤダ
    ウラ イヤ
ウラ ヤダヤダ
イイイヤハ プルル
```

出力は `3` です。条件が0でなくても繰り返しを終了できます。

```sh
printf '3\n2\n0\n' | yahalang run examples/break_on_zero.yaha --lang ko
```

出力は `32` です。0を読むと条件ブロック内で繰り返しを終了します。0より前の EOF は整数入力エラーになります。

## 配列の独立したコピー

`プル` は同じ配列への参照を複製します。`ヤダ ウララ` は内容を別の配列にコピーし、元の配列の上にコピーを積みます。一方を変更しても他方には影響せず、元の配列への既存の参照は引き続き共有されます。空の配列もコピーできます。スタック不足や型の不一致は、状態を変更せず実行時エラーになります。

```text
ヤダ ハヤハ
ハヤハ プル ヤハ
ヤダ プル
ヤダ ウララ
ハヤハ プルプル ヤハ
ヤダ プル
```

REPL で `:stack` を入力すると `[[1], [1, 2]]` になります。`ヤダ ウララ` の代わりに `プル` を使うと `[[1, 2], [1, 2]]` になります。

```sh
yahalang run examples/array_copy.yaha --lang ko
```

出力は `21`、コピーの長さ2と元の配列の長さ1です。句の途中の改行は使えますが、`;` は入れられません。

## 配列を文字として出力する

`ヤダ イイイヤハ` は配列内の整数を Unicode コードポイントとして順番に出力します。自動改行はなく、成功すると配列参照を1つ消費します。配列内容は変更しません。再利用する場合は先に `プル` で参照を複製してください。空の配列は何も出力しません。

```text
ヤダ ハヤハ
ウララ イイイヤハ
ヤダ プル
ウララ イイイヤハ
ヤダ プル
ヤダ イイイヤハ
```

入力 `Hi` を配列 `[72, 105]` に集め、`Hi` を出力します。

```sh
printf 'Hello, 안녕!\n' | yahalang run examples/print_character_array.yaha --lang ko
```

サンプルは EOF まで入力を集めてから配列全体を出力します。空白、改行、NUL も保持します。EOF の -1 は文字として配列に入れないでください。

全要素を検査してから出力するため、不正な文字値、型の不一致、スタック不足では何も出力せず状態を保持します。出力装置のエラーでも参照を保持しますが、送信済みの出力は元に戻せません。句の途中の改行は使えますが `;` は入れられません。

## 文字列入力

`ウララ ヤダ` は UTF-8 の1行を読み、Unicode コードポイントの新しい配列にします。末尾の LF または CRLF は除き、空白、タブ、NUL、単独の CR は保持します。空行は空の配列になり、改行なしで終わる最後の行も読めます。内容のない EOF は実行時エラーで、文字入力の -1 とは異なります。

```text
ウララ ヤダ
ヤダ イイイヤハ
```

`Hello` と Enter を入力すると、自動改行なしで `Hello` を出力します。

```sh
printf '가나다\n' | yahalang run examples/string_echo.yaha --lang ko
printf '가나🦀\n' | yahalang run examples/string_length.yaha --lang ko
```

出力はそれぞれ `가나다` と `3` です。長さは見た目の文字数ではなく Unicode スカラーの個数です。

不正な UTF-8、I/O エラー、改行を除いて1 MiBを超える行は、新しい値を積まずに実行時エラーになります。消費した入力は元に戻せません。REPL と同じ入力ストリームを使い、次の1行だけを読みます。句内の改行は使えますが `;` は入れられません。

## Yahalang で書かれたコンパイラ

[compiler/yahac.yaha](compiler/yahac.yaha) は、Yahalang で書かれた Yahalang→C コンパイラ yahac です。標準入力からプログラムを読み、単体で動く C プログラムを標準出力に書きます。英語・韓国語・日本語の表記は自動で判別しますが、1つのプログラムには1つの表記しか使えません。

```sh
yahalang run compiler/yahac.yaha --lang ko < examples/countdown.yaha > countdown.c
cc -O2 -o countdown countdown.c && ./countdown
```

コンパイルされたプログラムはインタプリタと同じ規則に従います。オーバーフローや UTF-8 の入出力も同じように扱い、エラー時は `haa? haa?` か `ui` を出力して終了コード 1 で終わります。コンパイルできないプログラムの場合、yahac は何も出力せず実行時エラーで止まります。

yahac は自分自身もコンパイルできます。そこから作ったネイティブのコンパイラは、同じ C コードをもう一度生成します。

```sh
yahalang run compiler/yahac.yaha --lang ko < compiler/yahac.yaha > yahac.c
cc -O1 -o yahac yahac.c
./yahac < compiler/yahac.yaha | cmp - yahac.c
```

Yahalang にはコメントも名前もないため、`yahac.yaha` は [compiler/gen_yahac.py](compiler/gen_yahac.py) が読みやすい記述から生成します。[compiler/runtime.c](compiler/runtime.c) は yahac がすべてのプログラムに含める C ランタイムです。どちらかを変更したら `python3 compiler/gen_yahac.py` を実行し、`python3 compiler/test_yahac.py` でコンパイル結果とインタプリタの結果を比べてください。
