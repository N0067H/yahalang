Yahalang は『ちいかわ』のうさぎラップのリフレインから文法を取った難解プログラミング言語です。\
うさぎの声を組み合わせた句を命令として使い、スタックに値を積んで計算します。符号付き64ビット整数と整数配列を扱い、韓国語・英語・日本語の表記に対応しています。

## はじめに

Rust と Cargo がインストールされた環境でビルドして実行します。

```sh
cargo build
cargo run -- run examples/hello_world.yaha --lang ko
```

`Hello, world!` と改行を出力します。このリポジトリのサンプルはすべて韓国語表記なので、`--lang ko` を付けて実行してください。

コードを入力しながら試すには、REPL を起動します。

```sh
cargo run -- repl --lang ja
```

```text
yaha> ハヤハ プルプル ヤハ
yaha> プル
yaha> ヤハ
yaha> :stack
[4]
yaha> イイイヤハ プルル
4
yaha> :q
```

2を積み、複製してから足す例です。REPL は次の入力にも値を引き継ぎます。複数行の入力や初期化については [REPL](#repl) を参照してください。

## スタックと数値

命令はスタックの一番上にある値を使います。この文書では左が下、右が上です。`[7, 2]` なら2が一番上にあります。

数値は `ハヤハ` で始め、`ヤハ` で閉じます。その間にある `プル` の個数が値になります。

| コード | 値 |
| --- | --- |
| `ハヤハ ヤハ` | 0 |
| `ハヤハ プル ヤハ` | 1 |
| `ハヤハ プルプル ヤハ` | 2 |

負の数は、数値を作った後に `ウラ ヤッ` で符号を反転して作ります。小数は扱えません。

```text
ハヤハ プルプル ヤハ
ハヤハ プルプルプル ヤハ
ヤハ
イイイヤハ プルル
```

2と3を積んで足し、`5` を出力します。出力した値はスタックから取り除かれます。

以下の表で `a` と `b` は値、`A` は配列への参照です。命令が成功したときに変化する部分だけを示しています。その下にある値は残ります。

| 句 | スタックの変化 | 動作 |
| --- | --- | --- |
| `プル` | `a → a, a` | 一番上の値を複製 |
| `ウラ プル` | `a → なし` | 一番上の値を捨てる |
| `イヤ プル` | `a, b → b, a` | 一番上の2つの値を交換 |

配列に `プル` を使うと、同じ配列を指す参照が1つ増えます。内容を別の配列にコピーする場合は [配列のコピー](#参照の複製と内容のコピー) を使います。

## 句の読み方

音は決められた表記どおりに書きます。`イヤ` や `ウラ` は使えますが、ダッシュを挟んだ `イ-ヤ` や `ウ-ラ` はエラーです。コメントや文字・文字列リテラルの文法はありません。

空白や改行は句を区切りません。`イイイヤハ` の次の行に `プルル` を書いても、1つの整数出力命令として読みます。インデントは自由です。

音は続けて書くこともできます。表記が重なるときは長いものを先に読みます。`プルプル` は複製2回ですが、`プルル` は別の音です。

隣り合う命令が1つの句にまとまるのを防ぐには、`;` で区切ります。

| コード | 解釈 |
| --- | --- |
| `イイイヤハ プルル` | 整数出力 |
| `イイイヤハ ; プル` | 整数入力の後に複製 |
| `ウラ ヤハヤハ` | 条件ブロックを閉じる |
| `ウラ ヤハ ; ヤハ` | 引き算の後に足し算 |
| `ヤハヤハ` | 足し算2回 |

1つの句や数値の途中に `;` は入れられません。たとえば `ハア ; ハッ`、`ヤダ ; プル`、`ハヤハ ; ヤハ` はエラーです。

## 計算と比較

2つの値を使う演算では、下の値が左辺、一番上の値が右辺になります。`[7, 2]` で引き算をすると `[5]` になります。

| 句 | スタックの変化 |
| --- | --- |
| `ヤハ` | `a, b → a + b` |
| `ウラ ヤハ` | `a, b → a - b` |
| `ハッ` | `a, b → a × b` |
| `ウラ ハッ` | `a, b → a ÷ b` の整数の商 |
| `ウラ ハッハッ` | `a, b → a % b` |
| `ウラ ヤッ` | `a → -a` |
| `ハア イヤ` | `a, b → a < b` なら1、それ以外は0 |
| `ハア ハッ` | `a, b → a == b` なら1、それ以外は0 |
| `ハア ヤハ` | `a, b → a > b` なら1、それ以外は0 |

割り算は0方向に小数部分を切り捨てます。-7を2で割った商は-3、余りは-1です。0による除算や、符号付き64ビット整数の範囲を超える計算はエラーになります。

比較できるのは整数同士だけです。2つの値を取り出して結果を1つ残すので、元の値が必要なら先に複製してください。不一致は等しいかどうかの結果を0と比較して表せます。以下・以上はそれぞれ、大きい・小さいかどうかの結果を0と比較して表せます。

## 条件と繰り返し

| 開始 | 終了 | 条件値の扱い |
| --- | --- | --- |
| `イヤ ヤハヤハ` | `ウラ ヤハヤハ` | 一番上の整数を取り出し、0でなければ本体を実行 |
| `イヤ ヤダヤダ` | `ウラ ヤダヤダ` | 一番上の整数を残したまま、0でない間繰り返す |

条件値は整数でなければなりません。ブロックは128段まで入れ子にでき、開始句と終了句の種類を合わせる必要があります。

### 条件文

```text
イイイヤハ
イイイヤハ
ハア イヤ
イヤ ヤハヤハ
    ハヤハ プル ヤハ
    イイイヤハ プルル
ウラ ヤハヤハ
```

1つ目の入力が2つ目より小さければ `1` を出力し、それ以外は何も出力しません。`ハア イヤ` が残した比較結果は、条件ブロックが取り出して使います。

### 繰り返し

```text
ハヤハ プルプルプル ヤハ
イヤ ヤダヤダ
    プル
    イイイヤハ プルル
    ハヤハ プル ヤハ
    ウラ ヤハ
ウラ ヤダヤダ
```

`321` を出力し、スタックに0を残します。繰り返しは本体を実行する前と、次の繰り返しに戻るときに一番上の整数を確認します。本体の末尾には、次の確認用の整数を残してください。最初から0なら本体を飛ばし、その0もスタックに残ります。

### 繰り返しからの脱出と実行終了

`ウラ イヤ` は最も内側の繰り返し1つから抜けます。条件文の中でも使えます。入れ子の繰り返しでは内側だけを終了し、スタックは変更しません。

```text
ハヤハ プルプルプル ヤハ
イヤ ヤダヤダ
    ウラ イヤ
ウラ ヤダヤダ
イイイヤハ プルル
```

条件値が3でも繰り返しを終了し、その後の命令で `3` を出力します。脱出する場合は、次の条件確認用の整数を残す必要はありません。繰り返しの外に書いた `ウラ イヤ` は構文エラーです。脱出後のコードも構文検査の対象になります。

`ヤッ` は繰り返しだけでなく、現在のプログラムの実行を終了します。ファイルの末尾でも終了するので必須ではありません。REPL では現在の入力の実行だけを終え、次の入力を受け付けます。

## 入出力

文字は Unicode コードポイントを表す整数として扱います。たとえば `あ` は12354です。文字列はこれらの整数を順番に並べた配列です。

| 句 | 入力または出力 | スタックの変化 |
| --- | --- | --- |
| `イイイヤハ` | 1行から整数1つを入力 | 整数を追加 |
| `ウララ イイイヤハ` | UTF-8 の文字1つを入力 | コードポイントを追加 |
| `ウララ ヤダ` | UTF-8 の1行を入力 | 新しいコードポイント配列を追加 |
| `イイイヤハ プルル` | 整数を出力 | 整数を消費 |
| `イイイヤハ ウララ` | 文字を出力 | 整数を消費 |
| `ヤダ イイイヤハ` | 配列を文字として出力 | 配列参照を1つ消費 |

出力命令は自動で改行しません。改行するには、コードポイント10を文字として出力するか、文字配列に含めてください。

### 整数入力

```sh
printf '12\n30\n' | cargo run -- run examples/add_two_numbers.yaha --lang ko
```

2行を読み、合計の `42` を出力します。整数は1行に1つずつ入力します。前後の空白は使えますが、`12 30` のように1行に2つ書くとエラーになります。

### 文字入力

```text
ウララ イイイヤハ
イイイヤハ ウララ
```

文字を1つ読み、そのまま出力します。`あ` を入力すると `あ` が出ます。最後の命令を `イイイヤハ プルル` にすると、コードポイントの `12354` を出力します。

空白や改行も文字として読みます。後続の文字や改行は先に消費しません。端末では Enter を押すまで入力が渡されない場合があり、その改行は次の入力に残ります。

### 文字列の入力と出力

```text
ウララ ヤダ
ヤダ イイイヤハ
```

1行を読み、そのまま出力します。`あいう` と Enter を入力すると `[12354, 12356, 12358]` を作り、`あいう` を出力します。

文字列入力は行末の LF または CRLF だけを取り除きます。前後の空白、タブ、NUL、単独の CR は残ります。空行は空の配列になり、改行なしで終わる最後の行も読めます。入力のたびに独立した配列を作ります。

長さを調べるには、出力の代わりに `ヤダ プルル` を使います。

```text
ウララ ヤダ
ヤダ プルル
イイイヤハ プルル
```

`あいう` を入力すると `3` になります。長さは画面に見える文字数ではなく、Unicode コードポイントの個数です。結合文字や複数のコードポイントからなる絵文字は、配列でも複数の要素になります。

文字配列の出力は先頭から順に行い、内容は変更しません。空の配列は何も出力しません。すべての文字値を検査してから出力するため、不正な値があれば出力もスタックも変更せずエラーにします。配列を再利用するなら、先に `プル` で参照を複製してください。

### EOF と入力制限

EOF の扱いは入力の種類で異なります。

| 入力 | EOF の扱い | 長さの制限 |
| --- | --- | --- |
| 整数 | 読む内容がなければエラー | 改行を含めて1行最大1,024バイト |
| 文字 | 文字の開始前なら-1、途中ならエラー | UTF-8 の文字1つ |
| 文字列 | 最後の内容があれば配列を返し、なければエラー | LF・CRLF を除いて1行最大1 MiB |

文字入力の EOF 値である-1は、有効な文字値ではありません。文字として、または文字配列の一部として出力する前に EOF かどうか確認してください。[character_echo.yaha](examples/character_echo.yaha) はこの確認を含め、EOF まで文字を出力します。

不正な UTF-8、整数として読めない入力、長さ制限を超える入力はエラーです。エラーになっても、すでに読んだ入力は元に戻りません。文字・文字列・整数の入力はすべて同じ入力ストリームを使います。

## 配列

空の配列は `ヤダ ハヤハ` で作ります。数値の開始とは異なり、閉じるための `ヤハ` は付けません。配列に入れられるのは整数だけで、添字は0から始まります。

| 句 | スタックの変化 | 動作 |
| --- | --- | --- |
| `ヤダ ハヤハ` | 新しい配列を追加 | 空の配列を作る |
| `ヤダ プル` | `A, 値 → A` | 末尾に整数を追加 |
| `ヤダ ウラ` | `A → A, 値` | 末尾の整数を取り除いてスタックに積む |
| `ヤダ ウララ` | `A → A, コピー` | 内容を独立した配列にコピー |
| `ヤダ プルル` | `A → 長さ` | 長さを調べる |
| `ヤダ イヤ` | `A, 添字 → 値` | 要素を読む |
| `ヤダ ハッ` | `A, 添字, 値 → なし` | 要素を変更 |
| `ヤダ イイイヤハ` | `A → なし` | 配列を文字として出力 |

追加と取り出しは配列参照を残します。長さの取得・要素の取得・変更・出力は参照を消費するので、再利用する場合は先に `プル` で複製します。

### 値の追加と取り出し

```text
ヤダ ハヤハ
ハヤハ プル ヤハ
ヤダ プル
ハヤハ プルプル ヤハ
ヤダ プル
ヤダ ウラ
イイイヤハ プルル
ヤダ ウラ
イイイヤハ プルル
```

1、2の順に追加して逆順に取り出し、`21` を出力します。

| 実行した句 | スタック |
| --- | --- |
| `ヤダ ハヤハ` | `[[]]` |
| 1を積んで `ヤダ プル` | `[[1]]` |
| 2を積んで `ヤダ プル` | `[[1, 2]]` |
| `ヤダ ウラ` | `[[1], 2]` |
| `イイイヤハ プルル` | `[[1]]` |
| `ヤダ ウラ` | `[[], 1]` |
| `イイイヤハ プルル` | `[[]]` |

ここでの角括弧は、スタックと配列の内容を示すための表記です。上のプログラム自体に記号は必要ありません。

### 参照の複製と内容のコピー

`プル` は同じ配列を指す参照を複製します。どちらの参照から変更・追加・取り出しをしても、もう一方から同じ変更が見えます。

`ヤダ ウララ` は別の配列を作って内容をコピーします。元の参照を残し、その上にコピーを積みます。

```text
ヤダ ハヤハ
ハヤハ プル ヤハ
ヤダ プル
ヤダ ウララ
ハヤハ プルプル ヤハ
ヤダ プル
```

REPL で続けて `:stack` を入力すると `[[1], [1, 2]]` になります。`ヤダ ウララ` の代わりに `プル` を使うと `[[1, 2], [1, 2]]` になります。

### 従来の記号による文法

配列リテラルと記号命令も引き続き使えます。

| 記号 | 同じ動作をする句 |
| --- | --- |
| `[]` | `ヤダ ハヤハ` |
| `#` | `ヤダ プルル` |
| `@` | `ヤダ イヤ` |
| `=` | `ヤダ ハッ` |

配列リテラルの要素はカンマで区切ります。`[ハヤハ ヤハ, ハヤハ プル ヤハ]` は `[0, 1]` を作ります。配列の中に別の配列は入れられません。

## REPL

完成した入力はすぐに実行し、スタックと配列を次の入力に引き継ぎます。数値・配列・ブロック・句が未完成なら `...>` で続きを受け付け、完成するまでは実行しません。

| 命令 | 動作 |
| --- | --- |
| `:stack` | スタックを下から上の順に表示 |
| `:reset` | スタック・配列と入力中のコードを初期化 |
| `:q`, `:quit` | 入力中のコードを捨てて終了 |

構文エラーでは入力中のコードだけを捨てます。実行時エラーではエラー時点の状態を残し、次の入力を受け付けます。すでに実行した命令は元に戻しません。EOF に未完成のコードが残っていればエラーを表示します。

完成した入力同士が1つの句にまとまることはありません。1行に `イイイヤハ` だけを入力すると整数入力を実行し、次の行の `プルル` を待つことはありません。

プログラムの入力命令も REPL のソースと同じ入力ストリームを使います。入力命令の実行中に入れた行は、ソースではなくプログラムの入力値として読みます。

出力に次のプロンプトが続かないよう、REPL は必要に応じて表示用の改行を補います。ファイル実行ではこの改行は追加しません。

## 言語設定

`--lang ja`、`--lang ko`、`--lang en` でソースの表記を選びます。1つのプログラムに複数の言語表記は混ぜられません。

```sh
cargo run -- set lang ja
```

既定の表記を保存する命令です。実行時の `--lang` が保存設定より優先され、両方とも指定がなければ英語を使います。

句の構造は同じで、音の表記だけが変わります。たとえば `ヤダ ウララ` は韓国語では `야다 우라라`、英語では `yada urara` です。

| 日本語 | 韓国語 | 英語 |
| --- | --- | --- |
| ハヤハ | 하야하 | hayaha |
| ハア | 하아 | haa |
| プル | 뿌루 | ppuru |
| プルル | 뿌루루 | ppururu |
| ヤハ | 야하 | yaha |
| イイイヤハ | 이이이야하 | iiiiyaha |
| ウララ | 우라라 | urara |
| イヤ | 이야 | iya |
| ヤダ | 야다 | yada |
| ウラ | 우라 | ura |
| ハッ | 핫 | hat |
| ヤッ | 얏 | yat |

設定ファイルには `lang = "ja"` のような TOML 形式で保存します。

| OS | パス |
| --- | --- |
| Linux | `$XDG_CONFIG_HOME/yahalang/config.toml` または `~/.config/yahalang/config.toml` |
| macOS | `~/Library/Application Support/yahalang/config.toml` |
| Windows | `%APPDATA%/yahalang/config.toml` |

## 実行の追跡

`run` または `repl` に `--trace` を付けると、実行する句、ソースの位置、スタックの内容を確認できます。

```sh
cargo run -- run examples/trace_stack.yaha --lang ko --trace
cargo run -- repl --lang ja --trace
```

サンプルは2を複製して足し、`4` を出力します。足し算の前後には次の記録が表示されます。

```text
[trace] examples/trace_stack.yaha:3:1 before "야하" stack=[2, 2]
[trace] examples/trace_stack.yaha:3:1 after "야하" stack=[4]
```

位置は `ファイル:行:列` で、行と列は1から数えます。列はバイト数ではなく文字数です。複数行にまたがる句は開始位置を使い、表示するときだけ空白を1つにまとめます。元のソースは変更しません。

| 表示 | 意味 |
| --- | --- |
| `before` | 命令を実行する前のスタック。入力待ちになる命令も先に表示 |
| `after` | 命令が成功した後のスタック |
| `error` | 失敗時点のスタックと原因。その命令の `after` は表示しない |

スタックは `:stack` と同じ順番で、配列は現在の内容で表示します。繰り返しは実行のたびに記録し、飛ばした本体は記録しません。条件ブロックの終了句には実行命令がないため、記録もありません。脱出命令や `ヤッ` で実行されなかった句も表示しません。

REPL のファイル名は `<repl>`、行番号は現在の入力内の位置です。状態の保持や初期化の動作は変わりません。構文エラーで実行できなかったコードには追跡記録がありません。

追跡記録は標準エラー、プログラムの出力は標準出力に送ります。別々のファイルにも保存できます。

```sh
cargo run -- run examples/trace_stack.yaha --lang ko --trace > result.txt 2> trace.log
```

`result.txt` には `4`、`trace.log` には追跡記録が入ります。Cargo のメッセージも標準エラーに含まれる場合があります。配列や繰り返しが大きいと記録も増えます。追跡記録の書き込みに失敗すると実行を止めますが、完了した命令は元に戻しません。

## エラーの確認

既定のエラーメッセージはうさぎの声です。原因と位置を確認するには `--error-style friendly` を付けます。

```sh
cargo run -- run examples/array_access.yaha --lang ko --error-style friendly
cargo run -- repl --lang ja --error-style friendly
```

未知の音、不正な句、数値やブロックの閉じ忘れ、繰り返しの外での脱出命令は実行前に検査します。実行中には、スタック不足、型の不一致、整数オーバーフロー、0による除算、不正な添字・文字値・入力などがエラーになります。

実行時エラーでスタックが必ず元に戻るわけではありません。命令によっては、引数がすでに取り出されている場合があります。配列の追加・取り出し・内容のコピーは、スタック不足や不正な引数で失敗しても状態を変更しません。空の配列からの取り出しも同様です。

文字配列の出力は文字値を事前に検査し、書き込みやバッファの送出に失敗しても配列参照を残します。ただし、すでに出力したバイトや消費した入力は元に戻せません。

## Yahalang で書かれたコンパイラ

[compiler/yahac.yaha](compiler/yahac.yaha) は、Yahalang で書かれた Yahalang→C コンパイラ yahac です。標準入力からプログラムを読み、単体で動く C プログラムを標準出力に書きます。英語・韓国語・日本語の表記は自動で判別しますが、1つのプログラムには1つの表記しか使えません。

```sh
cargo run --release -- run compiler/yahac.yaha --lang ko < examples/countdown.yaha > countdown.c
cc -O2 -o countdown countdown.c && ./countdown
```

コンパイルされたプログラムはインタプリタと同じ規則に従います。オーバーフローや UTF-8 の入出力も同じように扱い、エラー時は `haa? haa?` か `ui` を出力して終了コード 1 で終わります。コンパイルできないプログラムの場合、yahac は何も出力せず実行時エラーで止まります。

yahac は自分自身もコンパイルできます。そこから作ったネイティブのコンパイラは、同じ C コードをもう一度生成します。

```sh
cargo run --release -- run compiler/yahac.yaha --lang ko < compiler/yahac.yaha > yahac.c
cc -O1 -o yahac yahac.c
./yahac < compiler/yahac.yaha | cmp - yahac.c
```

Yahalang にはコメントも名前もないため、[compiler/gen_yahac.py](compiler/gen_yahac.py) が読みやすい記述から `yahac.yaha` を生成します。[compiler/runtime.c](compiler/runtime.c) は生成するすべてのプログラムに含まれる C ランタイムです。どちらかを変更したら、次の順序で再生成してテストします。

```sh
python3 compiler/gen_yahac.py
cargo build --release
python3 compiler/test_yahac.py
python3 compiler/test_regressions.py
```

比較テストは `target/release/yahalang` を使うため、先にリリース用インタプリタをビルドしてください。
