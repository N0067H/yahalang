<h1 align="center">Yahalang</h1>

<p align="center"><img src="image.png" alt="ちいかわのうさぎ" width="280"></p>
<p align="center"><a href="README_EN.md">English</a> · <a href="README.md">한국어</a> · 日本語</p>

Yahalang は『ちいかわ』のうさぎの声とうさぎラップのリフレインをもとにしたスタック型の難解プログラミング言語です。\
韓国語・英語・日本語の表記、符号付き64ビット整数、変更可能な整数配列に対応しています。

**文法に互換性のない変更があります。** 旧整数表記 `ura yaha`、旧命令 `ui`、行番号ジャンプは使えません。\
既存プログラムは新文法に変換してください。旧文法の自動判別はありません。\
詳細な仕様は [DESIGN.md](DESIGN.md)（韓国語）を参照してください。

## 実行

```sh
cargo build
cargo run -- run examples/hello_world.yaha --lang ko
cargo run -- run examples/countdown.yaha --lang ko
cargo run -- repl --lang ja
```

リポジトリのサンプルは韓国語表記です。上のファイル実行はそれぞれ `Hello, world!` と改行、`321` を出力します。\
REPL は入力した各行を独立したプログラムとして実行します。ブロックも同じ入力行で閉じてください。\
スタックと配列は次の入力に引き継ぎません。終了は `:q` または `:quit` です。

## 数値と命令

`ハヤハ` で数値を開始し、`プル` の個数を数え、`ヤハ` で閉じます。\
`ハヤハ ヤハ` は0、`ハヤハ プルプル ヤハ` は2です。数値内の空白・改行は値に影響しません。

| 日本語 | 韓国語 | 英語 | 動作 |
| --- | --- | --- | --- |
| `ハヤハ … ヤハ` | `하야하 … 야하` | `hayaha … yaha` | 整数リテラル |
| `ヤハ` | `야하` | `yaha` | 加算 |
| `ウラ ヤハ` | `우라 야하` | `ura yaha` | 減算 |
| `ハッ` | `핫` | `hat` | 乗算 |
| `ウラ ハッ` | `우라 핫` | `ura hat` | 整数除算（0方向に丸める） |
| `ウラ ハッハッ` | `우라 핫핫` | `ura hathat` | 剰余 |
| `ウラ ヤッ` | `우라 얏` | `ura yat` | 符号反転 |
| `プル` / `ウラ プル` | `뿌루` / `우라 뿌루` | `ppuru` / `ura ppuru` | 複製 / 破棄 |
| `イイイヤハ` | `이이이야하` | `iiiiyaha` | 整数入力 |
| `イイイヤハ プルル` | `이이이야하 뿌루루` | `iiiiyaha ppururu` | 整数出力 |
| `イイイヤハ ウララ` | `이이이야하 우라라` | `iiiiyaha urara` | Unicode文字出力 |
| `ヤッ` | `얏` | `yat` | 終了 |

二項演算ではスタックの下側が左オペランドです。出力は値を取り出し、自動改行しません。\
入力は1行に整数1個です。日本語・英語の表記は言語設計上の表記で、公式の歌詞表記ではありません。

## フレーズとブロック

`イヤ`、`ウラ` のようにダッシュなしで書きます。ダッシュはエラーです。\
`プルプル` のように続けて書けます。最長の音を優先するため `プルル` は `プル` と別のトークンです。\
空白・改行はフレーズを区切りません。`イイイヤハ` の次の行が `プルル` でも整数出力になります。

`;` はフレーズの結合を明示的に止めます。`ウラ ヤハヤハ` は条件ブロックの終了、\
`ウラ ヤハ ; ヤハ` は減算の後に加算です。単独の `ヤハヤハ` は加算2回です。\
数値やブロック開始・終了フレーズの途中に `;` は置けません。文字列・文字リテラル、コメントは未対応です。

| 開始 | 終了 | 動作 |
| --- | --- | --- |
| `イヤ ヤダヤダ` | `ウラ ヤダヤダ` | 先頭の整数が0でない間、繰り返す |
| `イヤ ヤハヤハ` | `ウラ ヤハヤハ` | 整数を取り出し、0でなければ本体を実行 |

繰り返し条件は値を取り出しません。開始時と各反復後に検査するため、本体は次の条件用の整数を残す必要があります。\
ブロックは128段まで入れ子にできます。空行やインデントは制御フローに影響しません。

```text
ハヤハ プルプルプル ヤハ
イヤ ヤダヤダ
    プル
    イイイヤハ プルル
    ハヤハ プル ヤハ
    ウラ ヤハ
ウラ ヤダヤダ
ヤッ
```

出力は `321` です。整数2個の加算は次のように書けます。

```text
イイイヤハ
イイイヤハ
ヤハ
イイイヤハ プルル
ヤッ
```

## 配列

```text
[ハヤハ ヤハ, ハヤハ プル ヤハ, ハヤハ プルプル ヤハ]
ハヤハ プル ヤハ @
イイイヤハ プルル
```

出力は `1` です。添字は0から始まります。空配列は `[]`、入れ子の配列は未対応です。\
`#` は配列を取り出して長さを返します。`@` は配列・添字を取り出して要素を返します。\
`=` は配列・添字・整数値の順で取り出して要素を変更します。\
`プル` で複製した参照は同じ配列を共有し、変更も共有されます。

## 設定とエラー

`run` と `repl` は `--lang en|ko|ja`、`--error-style usagi|friendly` に対応します。\
明示した言語オプションが保存設定より優先され、両方ない場合は英語です。\
既定値は `cargo run -- set lang ja` で保存できます。\
設定は `lang = "ja"` 形式の TOML で、Linux では `$XDG_CONFIG_HOME/yahalang/config.toml`\
（未設定時は `~/.config/yahalang/config.toml`）、macOS では `~/Library/Application Support/yahalang/config.toml`、\
Windows では `%APPDATA%/yahalang/config.toml` に保存されます。

既定のエラー表示は声のみです。`friendly` は理由と実際のソース位置を表示します。\
スタック不足、型違い、オーバーフロー、0除算、不正な入力・添字・Unicode値は実行エラーです。\
閉じていない数値・ブロック、未定義の音は構文エラーです。

## サンプルと検証

[examples](examples) に Hello World、加算、整数エコー、配列変更、カウントダウン、truth machine があります。\
すべて `--lang ko` で実行してください。truth machine は0か1を受け取り、1の連続出力は Ctrl-C で停止します。

```sh
cargo fmt --check
cargo test --release
```

GitHub Actions は書式・releaseテストを検査し、Linux x86-64、Windows x86-64、macOS Apple Silicon 用バイナリを作成します。\
公開時は Cargo.toml と Cargo.lock のバージョンを更新し、対応する `v` タグをプッシュします。\
リリースには圧縮ファイルと `SHA256SUMS` が添付されます。プレリリースタグはプレリリースとなり、手動実行は成果物の作成のみです。
